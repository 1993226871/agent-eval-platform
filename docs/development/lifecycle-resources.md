# 删除、资源配额与审计

实验列表提供删除入口。确认后，`DELETE /api/v1/experiments/{id}` 携带 UUID `idempotency_key`，返回 202 和删除状态。相同键可重试；另一实验不能复用该键。`GET /api/v1/experiment-deletions/{id}` 查询本人实验的清理进度。

删除首先标记 DELETING，取消排队、执行和未完成评分，并立即禁止查询证据、上报、完成、下载、复核及新模型发送。已发送的模型请求仍按实际用量结算或等待管理员对账。清理至少等待 300 秒，再按服务端登记的对象清单删除附件；对象删除失败会记录重试，不能提前报告清理完成。后台每次最多处理四个对象，使用 900 秒租约和独立调度线程。

清理移除任务、轨迹、证据、评分、人工复核和不再共享引用的预览副本，并释放附件及证据存储计数。原始草稿保留。模型请求和响应内容被抹除，数据库保护也会抹除后续迟到写入的内容；调用身份、价格、用量和额度账本继续保留。删除后的不透明对象标识会周期性再次清理，处理已经发出签名的迟到上传，因此存在持续的少量对象删除请求。DELETED 表示私人实验数据已清理，非承诺完全删除费用审计元数据。

## 资源预算

累计额度只控制付费模型调用。免费规则、Python 和存储另有资源限制，所有权威准入在 PostgreSQL 事务中完成。

| 每个空间的默认限制 | 默认值 |
| --- | ---: |
| 在线 Worker / 同时执行任务 | 5 / 2 |
| 附件与证据共用存储预算 | 1 GiB |
| 未删除实验 | 200 |
| 每类资源元数据 / 已发布版本总数 | 300 / 1,000 |
| 累计任务执行次数 | 10,000 |
| 累计指标评分作业 | 50,000 |
| 累计 Python 预留秒数 | 3,600 |

每个 API/Worker 部署共享数据库全局上限：50 个在线 Worker、20 个执行中任务。重新上线也必须准入，任务满载时留在队列。Python 每个持久作业保守预留 30 秒，处理租约恢复不重复收费；它与模型额度分开显示，未使用的保守秒数不返还。任务次数及评分作业次数没有周期重置，删除也不返还。管理员提高预算后，等待资源的评分会恢复，已完成指标不会重跑。

存储预算在事件、附件申请和冻结快照写入时原子检查。事件按 PostgreSQL JSON 文本字节的两倍预留投影空间，快照按实际 JSON 文本字节计数；这是可执行的逻辑预算，不是数据库磁盘占用测量。单任务原始事件最多 16 MiB，单份快照最多 32 MiB。附件每任务最多 128 个、每空间最多 10,000 个。冻结因预算不足而等待时，报告显示等待原因，不将其作为零分。

任务用例编码最多 768 KiB，实验和重评冻结配置最多 8 MiB。同步导出在加载正文前估算大小，超过 16 MiB 返回 413；较大证据应使用分页轨迹。报告摘要仅取评分标量，任务明细按页取正文并应用16MiB预算。每个 API 进程同时最多处理两个重读取、每个用户最多一个正文及一个摘要请求，超出返回 429。分页轨迹保持独立。

本人使用 `GET /api/v1/resource-limits` 查看预算和用量。管理员使用 `GET/POST /api/v1/admin/workspaces/{workspaceId}/resource-limits` 查看或调整；修改必须提供原因。管理员角色不提供读取或删除其他用户私人实验的旁路。

## 费用与审计

`GET /api/v1/quota/ledger/page` 按游标读取完整费用流水，浏览器金额使用十进制整数字符串。旧 `/quota/ledger` 保留近期列表接口。

`GET /api/v1/audit-events` 返回本人空间的分页审计。记录建号、凭证、目录变更、发布、启动、取消、删除、额度及模型配置操作；只保存动作枚举、UUID、操作者、来源和时间，不保存正文、密钥或自由文本。审计表禁止修改和删除。系统动作和用户动作分别标记来源。

界面在“累计额度”中显示资源用量，管理员的“资源限制”页签调整预算，“审计记录”查询操作并打开实验删除状态。

## 验证

`DeletionRaceIT` 覆盖迟到上传、在途验证、清理失败重试、跨空间对象、迟到模型响应抹除且费用仍可对账，以及共享预览版本的延后回收。`ResourceLimitIT` 覆盖并发 50 Worker / 20 任务准入、累计预算恢复、共享字节预算与重复事件不重计。另有真实 S3 删除、追加审计、HTTP 权限、分页费用及浏览器交互测试。

Python 实际执行仍取决于合格 Linux/runsc 节点验收；增加资源额度不会绕过强化沙箱检查。
