# 报告、轨迹与实验对比

工作台 `/workspace/reports/{experimentId}` 分开展示执行结束、质量判定、Outcome/Process、覆盖率和效率。通过率同时保留“通过/计划尝试”和“通过/可判定尝试”的分母；无有效评分显示未知，ERROR、缺失和WAITING_QUOTA均不伪造零分。

点击逐任务结果可查看当前正式评测轮次、实际套件、固定证据快照和哈希。每个指标显示自动结果、理由和证据引用。引用打开的是固定快照中的任务说明、输入、参考、输出、事件或附件元数据。附件下载仍经本人权限检查，不使用用户提供的任意URL。

轨迹树按明确的父子Span组织，允许乱序到达；孤儿和循环节点保持可见，超过100层单独展示。树的数据来自当前轨迹投影，分页载入，因此可能包含迟到内容或尚未载入的父节点。评分证据始终以固定快照为准。中间结果及附件名称仅以转义文本展示。

人工复核追加保存分数、依据、复核者和时间，保留原始自动评分，不改变自动通过率。历史重评也保留在数据库，正式报告选择最新正式轮次；PREVIEW不进入默认报告。

## 对比范围

`GET /api/v1/reports/comparison?left={id}&right={id}` 在一次只读可重复读事务中校验两个实验属于本人空间并读取双方报告。核对：

- 相同任务集版本、实际套件版本、评测器版本，以及模型/价格绑定。
- 每个案例与尝试对应的证据完整性和原始/修订范围。
- 相同尝试计划、评分覆盖范围，且执行/评测结束并存在可判定数据。

混合套件、未完成或配置不一致时返回具体原因，保留双方数值但不计算分数差。可直接比较时只返回每个维度的右减左差值，没有混合总分。

不同执行的证据哈希通常不同：哈希标识各自内容，不要求两次Agent输出相同。对比要求采集和评分范围一致。原始/修订范围通过该任务最早冻结的快照与实际轮次快照辨别；无新内容产生的新请求复用相同快照。这个检查偏保守，不提供统计显著性或因果结论。

## 重跑与重评

“重跑Agent”新建实验，固定原始任务集/套件/Agent版本与重复次数，新截止时间一小时后。SDK执行及工具副作用再次发生，评测再次计费，原实验保留。网络失败重试固定整份请求及幂等键。

“创建新一轮评测”只重新评测指定任务。默认使用原始证据；显式选择纳入迟到证据时可创建新快照。可以选择另一个已发布套件，报告会提示实际配置变化。LLM和Python仍分别受额度、沙箱及容量约束。

## JSON导出

`GET /api/v1/reports/experiments/{id}/export` 返回附件JSON，包含：

- 报告、分母、版本范围、逐任务自动结果和采集来源。
- 最新正式轮次的固定证据：任务、结束输出、事件、附件元数据与完整性问题。
- 追加的人工复核，以及可关联到run/trial/evaluator的result身份。

不复制完整experiment_snapshot或平台模型凭证，附件二进制通过授权下载获取。新快照以configuration_ref引用不可变实验配置及其SHA256，导出保留该引用；旧快照的导出仍移除重复experiment_snapshot，原始snapshot_hash标识数据库中的完整旧快照。不要用删减后的旧manifest重算原哈希。导出只读取当前授权空间，其他用户与管理员均不能越权读取私人报告。

摘要和对比在数据库投影评分标量，不载入全部原因、引用或无关套件字段。任务明细真正按页查询当前页指标正文，单次正文预算16MiB，超限返回413后应缩小页大小。摘要与当前页可并发读取；每个API进程合计两个重读取槽，每个用户同时最多一个正文和一个摘要请求。导出另受16MiB完整大小预算限制。

## 验证

`ReportComparisonIT`覆盖可比/不可比、覆盖率与两个分母、数据集/评测器/模型价格差异、迟到证据、导出关联和跨空间拒绝。HTTP测试覆盖Session访问及导出权限。前端轨迹测试覆盖乱序、循环、缺失、截断和脚本文本转义。

`scripts/verify_phase_b.py --web-smoke`先生成两套SDK真实轨迹及评分，再用Chromium核对报告、证据定位、人工复核、JSON导出、不可比提示和手机无横向页面溢出。测试使用模拟订单工具和规则，不进行付费模型调用。
