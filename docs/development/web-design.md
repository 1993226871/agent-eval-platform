# Web工作台设计与实现约定

目标是开发者管理可复现评测：资源检索、版本编辑、发起实验和核对结果。界面主要语言为中文，产品名AgentEval。

## 视觉与布局

- 页面背景sky `#F4F8FB`，内容surface `#FFFFFF`，正文ink `#20394C`，主要操作teal `#116772`，辅助文字muted `#627B8C`，失败状态critical `#AD452F`。
- 本地打包IBM Plex Sans，中文使用Microsoft YaHei/PingFang SC等系统字体。正文16px，表单/表格14px，页标题26px；代码编辑区单独使用等宽字体。
- 左侧导航220px，正文左对齐。资源列表承担检索，右侧编辑区承担草稿和版本切换。状态色表达执行/评分差异，版本与引用以明确文本和分隔呈现。
- 小屏将导航收拢、编辑区变为单列。按钮/链接有可见键盘焦点，原生dialog管理模态交互，尊重减少动态效果偏好。

```text
┌ 导航 ─────┬ 当前空间 / 页面操作 ──────────────────┐
│ 任务集    │ 资源列表       │ 草稿 / 已发布版本       │
│ 评测器    │ 名称、版本状态 │ 内容、校验、发布与试运行 │
│ 评分套件  │               │                        │
│ Agent     ├───────────────┴────────────────────────┤
│ 实验      │ 执行与评分分开，证据与分母可回查        │
│ 额度      │                                        │
└───────────┴────────────────────────────────────────┘
```

设计复核：管理台的主要工作是查看结构化版本和证据，因此以列表、编辑区、状态和明确的发布操作建立层次。视觉重点放在版本/执行范围的可辨识性，装饰不承担信息。

## 交互与边界

- 已发布版本只读；回到草稿后编辑。归档保留已发布版本和历史结果。错误呈现JSONL行号及可采取的修正方式。
- 强制首次改密码，401回登录并清除私人查询缓存。普通用户无管理员入口。Session同源Cookie，变更请求携带CSRF；密码/接入密钥不进localStorage。
- Worker密钥只在创建后当次显示，关闭后只保留无密钥元数据和撤销入口。
- 模型价格与累计额度使用整数字符串传输，前端BigInt计算预留估算，避免超出JS安全整数范围的舍入。
- 草稿试运行独立显示，模型计费与沙箱限制不因试运行而绕过。实验重跑和重评使用不同操作文案和说明。

## 工具链

Node22.23.4（下载SHA256已核验）；React19.3.1、Vite8.3.5、Router7.18.4、TanStack Query5.104.5、Zod4.6.7。OpenAPI TypeScript7.13.0要求TypeScript5.x，因此固定TypeScript5.9.3；具体传递依赖见web/package-lock.json。

类型由仓库OpenAPI生成并通过openapi-fetch调用。依据[OpenAPI TypeScript文档](https://openapi-ts.dev/introduction)和[Vite运行要求](https://vite.dev/guide/)。本机npm10在Windows使用相对--prefix安装时会尝试安装当前根目录，因此本地在web目录运行npm，未修改全局工具配置。
